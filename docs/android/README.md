# Android implementation target

Native app implementation target:

- Kotlin
- Jetpack Compose + Material 3
- Navigation Compose
- Android Photo Picker
- Retrofit + OkHttp
- Coroutines + Flow
- DataStore
- Coil

Suggested initial package name (change before publishing after checking availability): `app.tonalique.mobile`.

Start from the PRD and `design.md`. Build the UI against mocked Tonalique backend responses first, then connect the deployed FastAPI service. Do not add YouCam API credentials to Android config or assets.
