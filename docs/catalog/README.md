# Demo product catalogue

This folder is reserved for `demo_products.json`.

Before populating it:

- Use 12–20 product records with a real, accessible official brand/retailer source, or label fictional entries as demo-only.
- Record `source_url` and `source_checked_at` for each product.
- Do not guess price, finish, shade, ingredients or availability.
- Store prices as integer minor units and include ISO currency.
- Tie each previewable product to a reviewed `effect_config_id` in the backend effect registry.
- Do not imply that the hex palette or virtual preview guarantees the real product result.

No product listings are included yet because real products/prices need to be checked before they are represented as purchasable.
